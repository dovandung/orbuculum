# Orbuculum line counts

Shows, in front of every source line, how many times it ran. The numbers come from the lcov
file written by `orbprofile -c` (kept up to date by `orbprofile -l`).

Setting `orbLineCounts.coverageFile`: the file, default `coverage.info` in the workspace folder.
Command **Orbuculum: Show/Hide Line Counts**, or click **Counts** in the status bar.
